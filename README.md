<a id="contenido"></a>
## 📝 Contenido

En este repositorio se podrán encontrar:

- 📄 Actividades prácticas de la materia.
- 💻 Trabajos relacionados con desarrollo web.
- 📁 Archivos y recursos correspondientes a cada entrega.
- 📚 Trabajos Prácticos (TP).
- 🔗 Enlaces o recursos solicitados en las consignas.
- ✅ Otras actividades obligatorias que formen parte de la cursada.

Cada actividad o trabajo se encontrará dentro de su carpeta correspondiente para facilitar su identificación y revisión.

<a id="objetivo"></a>
## 🎯 Objetivo

El repositorio busca mantener un **registro ordenado de las entregas realizadas durante la cursada**, permitiendo verificar de forma clara:

- Las actividades realizadas.
- Los trabajos prácticos entregados.
- La organización de cada entrega.
- La evolución del trabajo durante la materia.
- El cumplimiento de las consignas solicitadas.


<a id="entregas"></a>
## 📌 Entregas

Las actividades y trabajos se irán incorporando al repositorio **a medida que sean solicitados y desarrollados durante la cursada**.
